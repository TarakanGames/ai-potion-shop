# AI Potion Shop

A terminal-based potion shop powered by a local AI.
Uses Python, Ollama (`qwen3-vl:8b`), and tool calling to manage inventory and player gold.

## How to Run

1. Pull the Ollama model: `ollama pull qwen3-vl:8b`
2. Install the package: `pip install ollama`
3. Start the game: `python AI_PotionShop.py`
